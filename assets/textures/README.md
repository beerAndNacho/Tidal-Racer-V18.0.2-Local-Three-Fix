# Tidal Racer local texture set

These project-local WebP textures were generated with the built-in OpenAI image generation tool and optimized to 1024 x 1024 for the V18 renderer.

- `coastal-facade-v1.webp`: front-facing weathered coastal commercial facade, blank signage, no logos or copied buildings.
- `facade-harbor-shops-v2.webp`: original weathered waterfront shop/apartment facade module.
- `facade-coastal-apartments-v2.webp`: original renovated coastal apartment facade module.
- `facade-marina-office-v2.webp`: original glass-and-metal marina office facade module.
- `facade-harbor-warehouse-v2.webp`: original painted concrete harbor warehouse facade module.
- `facade-marina-mixed-use-v3.webp`: original six-storey limestone/concrete marina apartment and blank-storefront facade module.
- `facade-marina-service-v3.webp`: original metal/concrete working-marina office and boat-service facade module.
- `asphalt-v1.webp`: neutral seamless dry urban asphalt.
- `concrete-v1.webp`: neutral seamless weathered concrete paving.
- `neoprene-suit-v1.webp`: seamless graphite neoprene micro-fabric refined from a generated rider-material study.
- `ocean-micro-height-v1.webp`: grayscale multi-scale ocean crest and foam-density texture.
- `fish-scales-v1.webp`: seamless silver-blue coastal fish scale albedo.
- `fish-skin-bluewater-v1.webp`: generated deep-blue/silver tuna and wahoo scale albedo.
- `fish-skin-tropical-v1.webp`: generated teal/gold iridescent tropical scale albedo.
- `fish-skin-reef-v1.webp`: generated charcoal/rust/olive mottled reef-fish scale albedo.

The three V18 fishing textures were cropped from a single project-exclusive three-panel atlas generated with the built-in image generation mode, then resized to 768 x 768 WebP (quality 88). The untouched source image remains in the Codex generated-image directory recorded in the task handoff.

The reference screenshots were used only to identify the desired natural-light material density. The generated facade does not reproduce their locations, branding, readable text, characters, or composition.

The four V2 facade modules were cropped from the project-exclusive source atlas `exec-c82aaf53-57ca-49f2-89d7-54fafc62e030.png`, resized to 1024 x 1024 and encoded as WebP quality 88. They contain no readable branding or copied game location.

The two V3 facade modules were generated independently with the built-in image-generation mode as frontal orthographic, edge-to-edge game textures. They were encoded as 1024 x 1024 WebP quality 92. Both prompts explicitly prohibited readable text, brands, trademarks, people, vehicles, copied locations and perspective convergence. Exact source identifiers and production-file hashes are recorded in `generated-provenance.json`.
