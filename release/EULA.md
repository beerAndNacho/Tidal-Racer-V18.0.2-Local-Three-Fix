## 4. Local saves and user files

The current build stores progression and preferences in the user's browser
storage. Save export creates a user-requested JSON file, and Photo Mode creates
a user-requested PNG file. The publisher does not operate cloud saves in this
build. Users are responsible for keeping backups of exported files. Resetting
browser site data can permanently remove local progression.
