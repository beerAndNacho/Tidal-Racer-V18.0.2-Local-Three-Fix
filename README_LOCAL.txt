TIDAL RACER V18.0.2 - LOCAL RUNTIME
====================================

WINDOWS / 윈도우
1. ZIP 파일을 새 폴더에 압축 해제합니다.
2. run_local.bat을 더블클릭합니다.
3. 브라우저에서 ENTER OPEN ARCHIPELAGO를 누릅니다.

Python, Node.js, npm 설치가 필요하지 않습니다. 실행기는 127.0.0.1에서만
로컬 서버를 열며 인터넷으로 게임 데이터나 개인 정보를 전송하지 않습니다.

MACOS / LINUX
1. Extract the ZIP into a new folder.
2. Run: sh run_local.sh
3. Python 3 is required.

CONTROLS / 조작
W/Up 전진, S/Down 브레이크/후진, A/Left 좌회전, D/Right 우회전
Space 드리프트/릴 감기, Shift 부스트/달리기, 1-4 스킬
E 아이템/도시 상호작용, F 레이스/자유주행, G 낚시
Q 캐스팅/훅, H 지역 활동, C 카메라, R 재시작
M 음악, L 언어, X 골든 코스트 부두에서 승하선

AUDIO / 오디오
브라우저 정책상 첫 화면에서 ENTER OPEN ARCHIPELAGO를 눌러야 BGM이 시작됩니다.

TROUBLESHOOTING / 문제 해결
- index.html을 직접 열지 말고 반드시 실행기를 사용하세요.
- 포트 8080이 사용 중이면 실행기가 8081-8090 중 빈 포트를 자동 선택합니다.
- 종료하려면 실행기 창에서 Ctrl+C를 누르세요.
