# V15 Character Direction

V15 replaces the single capsule rider with a modular articulated character system.

## Runtime layers
- Hero LOD: facial features, eye blink, hair pieces, layered life vest, helmet variants, gloves, boots and 18 articulated joints.
- Rival LOD: simplified facial detail while preserving a unique silhouette and full riding pose.
- States: menu idle, normal riding, hard turn, drift, boost, rough-water absorption and rider-specific victory pose.

## Diversity
All 16 riders have distinct body proportions, face proportions, hair, helmet, protective gear, posture, personality, origin, biography and signature victory pose. Diversity is used to create memorable identities rather than stat-only reskins.

## Asset upgrade path
The procedural rig is a fallback and validation layer. Licensed production GLBs can replace each rider through the asset manifest when they provide the documented bone names and animation states. Original third-party GLB source files are not redistributed unless the license explicitly permits it.
