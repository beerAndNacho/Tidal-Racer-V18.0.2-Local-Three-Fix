## 게시 전 체크

- 키아트에는 반드시 “홍보용 일러스트”라고 밝힌다.
- 실제 화면 녹화는 같은 공개 ZIP에서 촬영한다.
- GTA·AAA·포토리얼 완성작이라고 표현하지 않는다.
- 링크 없는 티저보다 다운로드 링크와 질문을 함께 둔다.
- 같은 문구를 반복 게시하지 않고 실제 수정·기록·실패를 후속 소재로 쓴다.
- 댓글의 버그는 브라우저, GPU, 재현 단계와 함께 GitHub Issue로 연결한다.
- 다운로드·별·Issue 수는 공개 데이터 그대로 기록하며 성공을 보장하지 않는다.
