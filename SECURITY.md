# Security policy

Tidal Racer is a local browser game. It does not require an account, API key,
cloud save, analytics service, or remote executable code. Progress is stored in
the browser's local storage.

## Reporting a vulnerability

Please open a GitHub issue with the label `security` and describe the affected
version and reproduction steps. If the report contains an exploit or sensitive
details, omit those details from the public issue and ask the maintainer for a
private reporting channel.

Do not include passwords, access tokens, personal data, or unrelated machine
information in a report.

## Supported version

Security fixes are applied to the latest public preview only.
